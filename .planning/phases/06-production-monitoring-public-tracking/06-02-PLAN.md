<objective>
Wire the job order number generator (built in 06-01) into the actual creation flow, and surface the resulting number on every internal staff surface that already lists job orders by description alone (D-01, D-04). This is the first user-visible slice of the number: after this plan, a Frontline Staff member creating a visit sees each job order's real number immediately, and that same number follows the job order onto the Cashier Dashboard and the Owner's Credit Requests queue.

Purpose: A number that exists in the database but is never assigned or displayed is not a working feature — this plan closes that gap for every job order created from here forward.
Output: `QueueEntryController::store()`/`::addJobOrder()` assign a real number at creation; three staff-facing Vue pages render it.
</objective>
