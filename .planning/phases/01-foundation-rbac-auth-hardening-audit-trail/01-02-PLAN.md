<objective>
Fix RESEARCH.md's Pitfall 1: `Password::defaults()` in `AppServiceProvider` currently only enforces complexity rules when `app()->isProduction()` is true, silently falling back to an 8-character-minimum-only rule everywhere else — meaning RBAC-06 is not actually satisfied in local/testing/staging. Remove the environment gate and repair the two existing tests whose fixture passwords no longer meet the (now always-on) complexity rule.

Purpose: RBAC-06 has no "production only" carve-out in its requirement text; this task closes that gap standalone, independent of the RBAC/audit skeleton being built in parallel.
Output: `Password::defaults()` enforces complexity in every environment; `SecurityTest.php` and `PasswordResetTest.php` use complexity-compliant fixture passwords; a new test proves the fix.
</objective>
