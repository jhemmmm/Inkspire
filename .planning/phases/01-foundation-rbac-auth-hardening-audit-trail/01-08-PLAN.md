<threat_model>

## Trust Boundaries

| Boundary                                        | Description                                                                                                                       |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Stale session cookie -> authenticated request   | A stolen or leftover session cookie from a device that has since been superseded by a newer login must not grant continued access |
| Idle authenticated session -> unattended device | A logged-in session left unattended past the configured window must not remain usable                                             |

## STRIDE Threat Register

| Threat ID       | Category           | Component                                           | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                             |
| --------------- | ------------------ | --------------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-01-04         | Spoofing           | `app/Http/Middleware/VerifySingleSession.php`       | mitigate    | A stolen session cookie used from a second device is invalidated on the legitimate user's next login (residual risk noted in RESEARCH.md: this does not stop an already-stolen-and-actively-used session before that point — accepted as the honest limit of a lockout-on-next-login model) |
| T-01-03         | Spoofing/Tampering | `app/Http/Middleware/EnforceIdleSessionTimeout.php` | mitigate    | An unattended, authenticated browser session is force-expired after the configured idle window, reducing the window an opportunistic physical-access attacker has                                                                                                                           |
| </threat_model> |
