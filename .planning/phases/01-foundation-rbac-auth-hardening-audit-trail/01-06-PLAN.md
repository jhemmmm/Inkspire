## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Owner/Admin-submitted deactivate action -> users.is_active | Route-model-bound `{user}` parameter is the only input; no free-text/body fields accepted, minimizing injection/tampering surface |
| Self-deactivation | An Owner/Admin must not be able to lock themselves out via this action |
