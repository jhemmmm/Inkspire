  <action>
    Run `php artisan make:migration create_system_configurations_table --create=system_configurations --no-interaction`. Columns: `$table->id();`, `$table->string('key')->unique();`, `$table->string('group');` (values: `security`, `business_rules`, `file_handling`), `$table->json('value');`, `$table->string('type');` (values: `integer`, `decimal`, `boolean`, `string`, `array`), `$table->string('label');`, `$table->text('description')->nullable();`, `$table->timestamps();`.

    Run `php artisan make:model SystemConfiguration --no-interaction`. Add `#[Fillable(['key', 'group', 'value', 'type', 'label', 'description'])]` and a `casts(): array` method returning `['value' => 'array']`. Add four static accessor methods, each `Cache::rememberForever("config.{$key}", ...)`-backed:
    - `getInt(string $key, int $default): int` — `(int) (static::where('key', $key)->value('value') ?? $default)` (note: `value` column decodes JSON automatically via the array cast when loaded through a model instance, but `::where(...)->value('value')` is a raw column read that bypasses casting — read the row via `static::query()->where('key', $key)->first()?->value ?? $default` instead, so the JSON cast applies, then cast to `(int)`).
    - `getBool(string $key, bool $default): bool` — same lookup pattern, cast to `(bool)`.
    - `getArray(string $key, array $default = []): array` — same lookup pattern, return the decoded array directly (already an array via the `value` cast) or `$default` if the key is missing.
    - `getString(string $key, string $default): string` — same lookup pattern, cast to `(string)`.
    Also add `public static function invalidate(string $key): void` calling `Cache::forget("config.{$key}")`, to be called by the future config-update controller (Plan 01-12) immediately after saving a changed row (RESEARCH.md Pitfall 5 — `rememberForever` has no TTL and must be invalidated explicitly on write, not left to expire).
  </action>
  <verify>
    <automated>php artisan test --compact --filter=SystemConfigurationTest</automated>
  </verify>
  <done>Migration creates the table with the exact column set; `SystemConfiguration::getInt('missing_key', 5)` returns `5` when no row exists; after inserting a row with `value` json-encoding `10`, `SystemConfiguration::getInt('the_key', 5)` returns `10` and is cached (a second call does not re-query, verified via `DB::enableQueryLog()`).</done>
