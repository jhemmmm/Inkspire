<objective>
Let the Cashier request On-Credit for a job order and the Owner approve or reject it asynchronously, posting an approved credit to a new `accounts_receivable` table (POS-08, D-06 through D-09).

Purpose: This is the last payment path (POS-01/02/03/07 cover Cash/Bank Transfer/GCash/Maya/Cancellation) — without it, a job order with no other payment option has nowhere to go.
Output: `accounts_receivable` table + model + policy; Cashier's credit-request flow; Owner's Credit Requests approval queue.
</objective>
