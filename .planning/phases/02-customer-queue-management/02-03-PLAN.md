No error state for file rejection belongs here (D-11 — DPI/format/size validation is Phase 3's job).

    Add a "+ Add Another Job Order" `Button` (variant `secondary`) calling `addRow()` below the row list, and an "Add to Queue" primary `Button` that calls a `submitIntake()` function: `intakeForm.post(QueueEntryController.store().url, { forceFormData: true, preserveScroll: true })` — use `forceFormData: true` because the payload contains files nested inside an array (Inertia auto-detects top-level files but nested-array files need this explicit flag per the official file-upload docs). Show `intakeForm.processing` as a disabled state on the submit button, and render `intakeForm.errors['job_orders.' + index + '.description']` / `.type` / `.file` via `InputError` under each row's respective field.
