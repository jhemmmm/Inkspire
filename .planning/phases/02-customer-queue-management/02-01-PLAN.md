## Trust Boundaries

| Boundary                                                              | Description                                                                                                                      |

| Browser (authenticated Frontline Staff session) -> CustomerController | Untrusted request input (`q`, form fields) crosses here; must never be trusted for mass-assignment or reflected without escaping |
