## Phase Goal

**As an** Artist, **I want to** take a Type B job order from consultation through a locked, approved design, **so that** the job order becomes ready for pricing at the Cashier and production never depends on an unfinished or unapproved design.

<objective>
Integrate the TOAST UI Image Editor into the Job Order Workspace. Per 04-RESEARCH.md, `@toast-ui/vue-image-editor` is Vue 2-only and must NOT be installed — this plan installs only the framework-agnostic `tui-image-editor`/`tui-color-picker` core packages and hand-writes a Vue 3 Composition API wrapper, verified against a real `npm run types:check` pass before it is wired into the real Send-for-Review flow.

Purpose: This is the one genuinely new integration risk in the whole phase (no in-repo precedent, no official Vue 3 wrapper, zero TypeScript types upstream). Task 1 isolates that risk into a small, self-contained wrapper component verified by the type checker alone; Task 2 only then wires it into real job-order data, including firing Plan 04-03's `startDesign` transition the moment the Artist commits to a design base and keeping the editor/verdict UI mutually exclusive with an outstanding review.
Output: Two new npm dependencies, `ToastImageEditor.vue`, a hand-written `.d.ts` ambient module shim, and the Design section of the Job Order Workspace page.
</objective>
