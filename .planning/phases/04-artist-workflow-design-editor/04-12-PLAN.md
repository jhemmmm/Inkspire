## Phase Goal

**As an** Artist, **I want to** take a Type B job order from consultation through a locked, approved design, **so that** the job order becomes ready for pricing at the Cashier and production never depends on an unfinished or unapproved design.

<objective>
Let an Artist use a client-supplied `.psd` file as a design's starting point, per D-22/D-23. Parsing and flattening happen entirely client-side via `ag-psd` (npm) — explicitly not server-side Imagick, the user's deliberate choice even though Imagick's PSD delegate is confirmed working on this box. This extends the *existing* "Import Reference Image" file input inside `resources/js/pages/artist/JobOrderWorkspace.vue` (the actual shipped location of that flow per Plan 04-04's SUMMARY — 04-CONTEXT.md's code_context guessed `ToastImageEditor.vue`, but the real import handler lives in the workspace page). No separate button or UI element.

Purpose: Extends D-11's "blank canvas or reference image" starting points to also accept the print shop's most common client-supplied asset format (layered Photoshop files) without adding server-side image-processing surface area.
Output: `ag-psd` as a new npm dependency and an extended `onReferenceFileChosen` handler that detects, parses, flattens, and fails loud on `.psd` input.
</objective>
