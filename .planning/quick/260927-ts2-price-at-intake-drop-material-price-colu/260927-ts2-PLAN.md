### 1c. Pricing action

New `app/Actions/POS/QuoteJobOrderLineAmount.php`, invokable, sitting next to
`ComputeJobOrderPrice.php`:

```
__invoke(PricingEntry $entry, ?float $widthFt, ?float $heightFt, int $quantity): ?float
```

- If `strtolower($entry->unit ?? '')` starts with `'sq ft'` (real seeded units include `'sq
ft'`, `'sq ft (150 installed)'`, `'sq ft (65 installed)'`, etc. — verified in
  `database/seeders/PricingDatabaseSeeder.php` — a prefix match is correct, not an exact
  match): return `null` if either `$widthFt` or `$heightFt` is null, otherwise
  `round((float) $entry->base_price * $widthFt * $heightFt * $quantity, 2)`.

- One-line PHPDoc note that unit is free text and this is a prefix match; add a unit enum on
  `pricing_database` later if more unit shapes appear.

Depends on Task 1 (`display_total`, `quoted_amount`, `width_ft`, `height_ft` columns) but not
on Task 2 — this task's controllers and tables are independent of the intake form.

### 3a. `cashier/Dashboard.vue` — Total / Balance columns

`app/Http/Controllers/Cashier/DashboardController.php::index()` already selects `total_amount`
and computes `amount_paid` via `withSum` — **no controller change needed** beyond adding
`quoted_amount` and `is_rush` (already selected) to the `get([...])` column list so
`display_total` resolves correctly (it appends itself automatically per 1d — no `->append()`
call needed).

`resources/js/pages/cashier/Dashboard.vue`: the `CashierJobOrder` interface (~line 44) already
has `total_amount`/`amount_paid` but the table (headers ~268–274, rows starting ~284) never
renders them. Add `display_total: number | null;` to the interface. Add "Total" and "Balance"
`TableHead`s (right-aligned) and matching `TableCell`s using `money()` from `lib/jobOrders.ts`
and `tabular-nums`. Total shows `display_total`, with a muted "Est." `Badge` next to it when
`total_amount` is null. Balance shows `Math.max(0, (total_amount ?? display_total ?? 0) -
(amount_paid ?? 0))`, or `—` when both are null. Update the `:colspan` on both `TableEmpty`s to
match the new column count.

### 3b. `frontline-staff/Dashboard.vue` — both tables

`app/Http/Controllers/FrontlineStaff/DashboardController.php`: neither `index()`'s
`readyForPickup` query nor `search()` currently selects any money columns. Add
`total_amount`, `quoted_amount`, `is_rush` to both `select()`/`get([...])` lists, add a
`withSum(['transactions as amount_paid' => fn ($q) => $q->where('status',
TransactionStatus::Completed->value)], 'amount')` to both queries (import
`App\Enums\TransactionStatus`, mirror the exact cast-to-float-or-null pattern already used in
`Cashier/DashboardController.php`'s `->each(fn (JobOrder $jobOrder) => $jobOrder->amount_paid =
...)`). `display_total` appends itself automatically (per 1d) once those columns are selected —
no `->append()` call needed.

`resources/js/pages/frontline-staff/Dashboard.vue`: add `total_amount`, `quoted_amount`,
`is_rush`, `display_total`, `amount_paid` to both `ReadyForPickupJobOrder` and
`JobOrderSearchResult` interfaces. Add Total/Balance columns to both tables, same
money()/tabular-nums/"Est." badge treatment as 3a.

### 3c. `frontline-staff/QueueList.vue` — inline job price + visit Total column

`app/Http/Controllers/FrontlineStaff/QueueEntryController.php::index()`: the `jobOrders`
eager-load currently uses the column-shorthand form
(`'jobOrders:id,queue_entry_id,description,type,status,validation_failure_reason,assigned_artist_id,payment_status,released_at,number'`).
Convert it to a closure so a `withSum` can be attached:
`'jobOrders' => fn ($query) => $query->select([...existing columns..., 'total_amount',
'quoted_amount', 'is_rush'])->withSum(['transactions as amount_paid' => fn ($t) =>
$t->where('status', TransactionStatus::Completed->value)], 'amount')->with('assignedArtist:id,name,artist_label')`.
`display_total` appends itself automatically on every loaded `jobOrders` row (per 1d) once
`total_amount`/`quoted_amount`/`is_rush` are in the `select()` list above — no explicit
`->append()` call needed, including on this nested relation.

`resources/js/pages/frontline-staff/QueueList.vue`: add `total_amount`, `quoted_amount`,
`is_rush`, `display_total`, `amount_paid` to `JobOrderRecord` (~line 59). Show each job order's
price inline next to its description in the Job Orders cell (~line 330, next to `{{
jobOrder.description }}`) using `money(jobOrder.display_total)` with the "Est." badge rule.
Add a visit-level "Total" `TableHead`/`TableCell` (headers ~line 271, rows ~line 316) summing
`display_total` (or `0`) across `entry.job_orders`.
